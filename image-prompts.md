# Image assets and generation record

All photographs were created using the built-in OpenAI image generation tool for this project. No stock photographs or reference screenshot crops are used. Images are illustrative; the comparison gallery does not document actual customer work. No assets are missing.

Final local files are in `assets/images/`, optimized as WebP. The closing banner deliberately reuses the villa photograph with a wider display crop. Clean comparison images reuse the corresponding original photographs. Before images are separately generated edits of those originals, so minor generative differences can occur.
