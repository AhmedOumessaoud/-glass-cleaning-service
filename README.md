# Glass Clean

Open index.html directly in a modern browser. No installation, build tool, or framework is required. Upload index.html, style.css, script.js and the assets folder together to any static web host.

Arabic RTL landing page. WhatsApp: https://wa.me/212660866055. Each service plan adds an Arabic message. No prices are displayed. Sample testimonials and generated comparison images are explicitly labeled.

Images are local WebP assets; Cairo loads from Google Fonts with an Arial fallback. Image prompts and provenance are documented in image-prompts.md.

Validation: Microsoft Edge via Playwright at viewport widths 360, 390, 768 and 1440. No horizontal overflow, no broken images, no JavaScript errors. Checked WhatsApp target and all three prefilled plan messages, mobile menu open/close, and comparison slider input updates. Full-page previews are in previews/.
